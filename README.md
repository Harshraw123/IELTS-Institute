# IELTS Elite Institute - Modern Web Application

A cutting-edge, professional IELTS Institute website built with React, TypeScript, and Tailwind CSS. Features a futuristic design with glassmorphism effects, AI-powered learning highlights, and responsive layout.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

## 🎨 Design Features

- **Modern Glassmorphism UI**: Elegant glass-card effects with backdrop blur
- **Professional Blue-Purple Gradient Palette**: Carefully crafted color system for trust and innovation
- **Responsive Design**: Seamless experience across desktop, tablet, and mobile
- **AI-Powered Branding**: Emphasizes cutting-edge technology in education
- **Smooth Animations**: Professional fade-ins, hover effects, and transitions

## 📱 Components

### Core Sections
- **Navbar**: Fixed glass navigation with mobile-responsive menu
- **Hero**: Compelling headline with AI-focused messaging and stats
- **Features**: 4 key offerings with hover animations and glassmorphism cards
- **Testimonials**: Student success stories with avatars and achievement badges  
- **Footer**: Comprehensive contact info, social links, and newsletter signup

### Design System
- Professional blue-purple color palette (HSL-based)
- Custom glassmorphism utilities and button variants
- Semantic design tokens for consistent theming
- Professional typography with gradient text effects

## 🛠️ Technology Stack

- **Next js** for SEO
- **Tailwind CSS** for styling
- **Lucide React** for icons
- **shadcn/ui** components (customized for brand)

## 🎯 Key Features Highlighted

1. **AI Band Score Prediction** - Instant, accurate scoring
2. **Speaking Practice with AI** - Real-time pronunciation feedback  
3. **Automated Mock Tests** - Unlimited practice with analytics
4. **Live Expert Classes** - Interactive sessions with instructors

Built for professional IELTS education with emphasis on modern AI technology and proven student success.
